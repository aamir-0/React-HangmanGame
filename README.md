# 🎮 Assembly: Endgame - Hangman Game

A fun and interactive hangman game built with React as part of my journey learning React development. Save the programming world from Assembly by guessing the correct words!

## 🚀 Live Demo

[Play the Game](https://aamir-0.github.io/hangman) 

## 🎯 About This Project

This project was created as part of my React learning journey following the Scrimba React course. It's a modern take on the classic hangman game where players guess programming language names to prevent the world from falling into Assembly language chaos!

### What I Learned

- **React Hooks**: useState for state management
- **Event Handling**: onClick events and keyboard interactions  
- **Conditional Rendering**: Showing different UI based on game state
- **Array Methods**: map(), filter(), every() for game logic
- **CSS Animations**: Creating engaging visual effects
- **Component Architecture**: Building reusable React components
- **Deployment**: Using Vite + GitHub Pages for hosting

## ✨ Features

- 🎲 **Random Word Selection**: Each game starts with a random programming language
- 🎹 **Interactive Keyboard**: Click letters to make guesses
- 🎊 **Win Animation**: Confetti celebration when you win!
- 💥 **Loss Animation**: Shake effect with falling crosses when you lose
- 📱 **Mobile Responsive**: Play on any device
- 🌟 **Animated Background**: Beautiful gradient and particle effects
- ♿ **Accessible**: Screen reader friendly with proper ARIA labels

## 🛠️ Technologies Used

- **React 18** - UI library
- **Vite** - Build tool and dev server
- **CSS3** - Styling with animations and gradients
- **react-confetti** - Win celebration effects
- **clsx** - Conditional CSS classes
- **GitHub Pages** - Deployment

## 🚀 Getting Started

### Installation & Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Head over to https://vitejs.dev/ to learn more about configuring vite

### Building for Production

```bash
npm run build
```

### Deploying to GitHub Pages

```bash
npm run deploy
```

## 🎮 How to Play

1. **Start the Game**: A random programming language name is selected
2. **Make Guesses**: Click letters on the keyboard to guess
3. **Win Condition**: Guess all letters correctly before running out of attempts
4. **Lose Condition**: Make too many wrong guesses and Assembly takes over!
5. **New Game**: Click "New Game" button to play again
